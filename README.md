# משהו מתוק 🍰

האתר של "משהו מתוק" – קונדיטוריה ביתית באלון מורה.
אתר סטטי (Jekyll), בלי שרת ובלי עלות, שמתארח בחינם ב-GitHub Pages.
GitHub Pages בונה את האתר לבד אחרי כל שמירה – בלי GitHub Actions.

**עריכת תוכן:** דרך [Pages CMS](https://app.pagescms.org) – ראו **[מדריך-עריכה.md](מדריך-עריכה.md)**.
ב-Pages CMS מופיעים בכוונה רק **מוצרים** (הוספה, מחיקה, שם, תמונה, מחירים) ו**פרטי קשר**.
כל השאר (מארזים, קטגוריות, טעמים, טקסטים) נערך בקבצים שבטבלה למטה.

## מה יש בתיקייה

| קובץ / תיקייה | מה זה |
|---|---|
| **`_products/`** | **מוצר אחד בכל קובץ** (שם, תמונות, גדלים ומחירים, טעמים, הסתרה, סדר) |

| **`_data/settings.yml`** | הגדרות כלליות: פרטי העסק, טקסטים, כשרות, אלרגנים, פרטים משפטיים |
| **`_data/box_builder.yml`** | טעמי הקראמבל וסוגי העוגיות ב"הרכיבו מארז" |
| `.pages.yml` | ההגדרות של מסכי העריכה ב-Pages CMS |
| `index.html` | עמוד הבית (תבנית Jekyll – המוצרים והמארזים נכתבים לתוכו בזמן הבנייה) |
| `orders.html`, `privacy.html`, `accessibility.html` | עמודי המדיניות |
| `_layouts/`, `_includes/` | החלקים המשותפים: ראש העמוד, תחתית, אייקונים |
| `_includes/site-data.js` | נבנה אוטומטית מהתוכן ונכתב לתוך עמוד הבית – הנתונים לכרטיס המוצר, לסל ולהרכבת מארז |
| `script.js` | כרטיס מוצר, סל, הרכבת מארז (לא צריך לגעת) |
| `layout.js` | תפריט בטלפון ותפריט נגישות (לא צריך לגעת) |
| `styles.css`, `fonts/`, `fonts.css` | העיצוב והגופנים |
| `images/products/` | תמונות המוצרים – זו התיקייה שמופיעה ב-Pages CMS. תמונה שאף מוצר לא משתמש בה נמחקת אוטומטית (`.github/workflows/remove-unused-photos.yml`) |

| `reference/` | תמונות התפריט המודפס (לא מוצגות באתר) |

## הפעלת GitHub Pages (פעם אחת)

1. ב-repository: **Settings** ← **Pages**.
2. **Source**: `Deploy from a branch`, **Branch**: `main`, תיקייה `/ (root)` ← **Save**.
3. אחרי דקה–שתיים האתר זמין בכתובת `https://USERNAME.github.io/REPO/`.

אם כתובת האתר משתנה – מעדכנים את `seo.site_url` ב-`_data/settings.yml`
(משמש לתצוגה המקדימה בוואטסאפ).

## חיבור Pages CMS (פעם אחת)

1. נכנסים ל-[app.pagescms.org](https://app.pagescms.org) עם חשבון GitHub ומאשרים גישה ל-repository.
2. כדי שבעלת העסק תוכל לערוך: ב-GitHub ← **Settings** ← **Collaborators** ← **Add people**
   ← שם המשתמש שלה ב-GitHub (הרשאת **Write**). היא תקבל הזמנה במייל ותאשר.
3. משם הכול לפי [מדריך-עריכה.md](מדריך-עריכה.md).

## תמונות

- תמונות שמועלות ב-Pages CMS נשמרות ב-`images/products/` (עם שם אקראי, כדי שלא יהיו בעיות עם שמות בעברית).
- אם אין תמונה (או שהיא לא נטענת) מופיע במקומה כרטיס ורוד עם שם המוצר – לא תמונה שבורה.
- חשוב שהתמונות יהיו קלות (עד 1–2MB, ועדיף ~300KB) – כך האתר ייטען מהר בטלפון.
  אתר חינמי להקטנה והמרה: [squoosh.app](https://squoosh.app).

### המרה אוטומטית ל-WebP (אופציונלי, למי שנוח עם טרמינל ב-Mac)
1. שמים את התמונות המקוריות (JPG/PNG) ב-`images/originals/`.
2. מתקינים פעם אחת: `brew install webp`
3. מריצים: `bash optimize-images.sh`
4. התמונות המוכנות (WebP, רוחב עד 1200px) יופיעו ב-`images/products/`.

## בדיקה במחשב (אופציונלי)

צריך Ruby ו-Jekyll (אותה גרסה ש-GitHub Pages משתמש בה):
```bash
gem install jekyll -v 3.10.0 kramdown-parser-gfm webrick
jekyll serve --safe
```
ואז פותחים בדפדפן: http://localhost:4000

> חשוב: לא פותחים את `index.html` ישירות מהתיקייה – הוא תבנית, והתוכן נכנס אליו רק בבנייה.
